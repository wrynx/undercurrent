# Contributing

Contributions are welcome. See
[`CONTRIBUTING.md`](https://github.com/wrynx/undercurrent/blob/main/CONTRIBUTING.md)
in the repository for how to set up a development environment, run the tests
and open a pull request.

Everyone taking part in the project is expected to follow the
[code of conduct](https://github.com/wrynx/undercurrent/blob/main/CODE_OF_CONDUCT.md).
To report a security issue, follow the
[security policy](https://github.com/wrynx/undercurrent/blob/main/SECURITY.md)
instead of opening a public issue.
